Computing for Engineers MATLAB projects

A variety of projects including:
  Mini Yelp App: reads in restaurant data and recommends a restaurant based on distance
  Motion Detection: performs real-time analysis on camera frames to detect motion through image comparison and object detection
  Image Processing: A couple examples of image processing including green screening and adjusting RGB values
  Anonymous Functions: a program demonstrating the use of anonymous functions in solving physics problems
  Data Analysis and Regression: analyzes data through fitlines and regression to make predictions on values
  Morse Code Telegraph: a larger project involving an Arduino telegraph key, signal processing and an App Designer application to send and receive Morse code messages

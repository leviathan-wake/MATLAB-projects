# Morse Code Telegraph
Project utilizing MATLAB App Designer and an Arduino Uno R3 board to:
* Calibrate thresholds for input processing
* Receive input through a photoresistor
* Process the input to determine when they key/photoresistor has been pressed or not
* Visualize output through a graph and output to LEDs

<br>

## Arduino Pin Assignments (Uno R3)
* LED Pins: digital pins D4, D5, D6
* Photoresistor pin: analog pin A0

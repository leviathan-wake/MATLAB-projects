MATLAB program to perform data analysis on a dataset about various cars, relating miles per gallon (mpg) and horsepower
  read data from a .csv file and format it to make it more useable
  create scatterplot of mpg vs. horsepower
  plot linear and quadratic fitlines using polyval()
  perform least squares regression for each fitline
  determine which model is the best
  make some predictions using the best fitline
